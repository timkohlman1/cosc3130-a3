\textbf{Overview}
\begin{itemize}
    \item This research focuses on evaluating the integration of multimodal content within context-aware fake news detection models.
    \item The study aims to investigate how combining multimodal features with social context affects detection performance.
    \item The research questions are designed to break the problem into key sub-problems related to model performance and component contribution.
\end{itemize}

\textbf{RQ1: Effect of Multimodal Content Integration}
\begin{itemize}
    \item How does replacing a text-only content branch with a multimodal content branch affect the performance of context-aware inauthentic social media content detection models, and to what extent?
    
    \item Significance:
    \begin{itemize}
        \item Evaluates whether multimodal representations improve detection accuracy.
        \item Provides direct comparison with existing context-aware models such as DANES and GETAE.
        \item Helps quantify the performance gain from incorporating visual features alongside text.
    \end{itemize}
    
    \item Why it is important:
    \begin{itemize}
        \item Addresses a key limitation in current models that rely on text-only content.
        \item Helps determine if multimodal integration is worth the added complexity.
    \end{itemize}
\end{itemize}

\textbf{RQ2: Contribution of Model Components}
\begin{itemize}
    \item How does the relative contribution of the multimodal content branch and the social content branch affect overall detection performance?
    
    \item Significance:
    \begin{itemize}
        \item Analyses the importance of different components within the model.
        \item Identifies whether content features or social context features contribute more to performance.
    \end{itemize}
    
    \item Why it is important:
    \begin{itemize}
        \item Supports better design of hybrid detection frameworks.
        \item Helps prioritise which components should be optimised in future models.
    \end{itemize}
\end{itemize}
