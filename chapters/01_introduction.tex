\subsection{Introduction}

\textbf{Topic and Importance}
\begin{itemize}
    \item Social media platforms contain both authentic and inauthentic content.
    \item Inauthentic content is increasingly produced by malicious actors.
    \item Advances in generative AI enable creation of highly realistic:
    \begin{itemize}
        \item Text
        \item Images
        \item Video and audio
    \end{itemize}
    \item This makes fake content:
    \begin{itemize}
        \item Harder to detect
        \item More scalable
    \end{itemize}
    \item This creates risks for:
    \begin{itemize}
        \item Public trust
        \item Information integrity
    \end{itemize}
    \item Therefore, detecting inauthentic social media content is a critical research problem.
\end{itemize}

\textbf{Background and Existing Work}
\begin{itemize}
    \item Early fake news detection approaches focused on text-only analysis.
    \item These methods used:
    \begin{itemize}
        \item Natural Language Processing (NLP)
        \item Machine learning models
    \end{itemize}
    \item Limitation:
    \begin{itemize}
        \item Text alone is often insufficient for detection
    \end{itemize}
    \item Multimodal approaches combine:
    \begin{itemize}
        \item Textual features
        \item Visual features
    \end{itemize}
    \item Prior studies show multimodal models outperform unimodal models.
    \item Another research direction uses social context:
    \begin{itemize}
        \item User interactions
        \item Propagation patterns
        \item Engagement behaviour
    \end{itemize}
    \item Models such as DANES and GETAE incorporate social network information.
\end{itemize}

\textbf{Research Gap}
\begin{itemize}
    \item Existing approaches are divided into:
    \begin{itemize}
        \item Multimodal content-based models
        \item Social context-based models
    \end{itemize}
    \item Context-aware models (e.g. DANES, GETAE) still rely on:
    \begin{itemize}
        \item Text-only content branches
    \end{itemize}
    \item Multimodal models often do not fully integrate social context.
    \item There is limited research on:
    \begin{itemize}
        \item Combining multimodal content with strong social context frameworks
        \item Replacing text-only content components within existing architectures
    \end{itemize}
\end{itemize}

\textbf{Proposed Approach}
\begin{itemize}
    \item This research proposes a context-aware misinformation detection framework.
    \item Key idea:
    \begin{itemize}
        \item Replace the text-only content branch
        \item With a multimodal content branch (text + image)
    \end{itemize}
    \item The framework builds on existing models such as:
    \begin{itemize}
        \item DANES
        \item GETAE
    \end{itemize}
    \item The goal is to evaluate whether multimodal integration improves detection performance.
\end{itemize}

\textbf{Significance of the Research}
\begin{itemize}
    \item Provides insight into the value of multimodal features in context-aware systems.
    \item Contributes to improving robustness of fake news detection models.
    \item Addresses challenges posed by AI-generated misinformation.
    \item Supports advancements in:
    \begin{itemize}
        \item Social media data mining
        \item Fake news detection research
    \end{itemize}
\end{itemize}
